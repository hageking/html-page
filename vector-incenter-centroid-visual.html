ベクトルを「図」で追う

問題は指定どおり ② → ① の順です。右側の手順を押すと、図の強調部分が切り替わります。

② 内心 P の位置

AB = 8, BC = 7, CA = 9
AP = 3/8 b + 1/3 c
内心 P (3/8) b (1/3) c

押して順番に確認

1. 内心の重みを見る内心は「向かい側の辺の長さ」を重みにして表せます。
2. A を基準に変えるB − A = b、C − A = c を使います。
3. AP を2本のベクトルに分ける青とオレンジを足したものが AP です。
P = (7A + 9B + 8C) / 24

なぜ 7, 9, 8 かというと、A・B・C の係数には、それぞれ向かい側の辺 BC, CA, AB の長さが入るからです。

結論
AP = (9b + 8c) / 24 = 3/8 b + 1/3 c

① G から G′ への移動

D は BC を 2:3 に内分、E は 1:2 に外分
GG′ = 8/15 (b − c)
D：2:3 内分 E：1:2 外分 GG′ の向き

押して順番に確認

1. D と E を作る内分と外分を位置ベクトルで表します。
2. 2つの重心を作る各三角形の3頂点を足して3で割ります。
3. G′ − G を取るa が消え、b − c だけが残ります。
D = (3b + 2c) / 5
E = 2b − c

D は BD:DC = 2:3 なので係数は逆に 3 と 2。E は B の外側にあり、E = 2B − C になります。

結論
GG′ = 8/15 (b − c)
図では b − c = CB の向きなので、G から G′ へは BC に平行に左向きへ移動します。
