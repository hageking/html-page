状態図の場所の覚え方
＋ 問題210の解き方

教科書の図を「丸暗記」せず、温度と圧力が粒子に何をするかから判断できるようにする。後半では、問題210の結晶分類を見分ける順番まで整理する。

温度 → 右ほど高い
圧力 → 上ほど高い
右下ほど気体になりやすい
状態図の覚え方 境界線 水とCO₂ 問題210 確認問題

状態図は「右＝熱い、上＝押す」で覚える

右へ行く → 温度が上がる → 粒子が動く → 気体に近づく
上へ行く → 圧力が上がる → 粒子を押し込む → 液体・固体に近づく

この2本だけで、状態図の大まかな位置は判断できる。低温側の左は粒子が動きにくいので固体、高温・低圧側の右下は粒子が広がりやすいので気体になる。

左側：固体 中央〜上側：液体 右下：気体
最重要の覚え方：「熱くすると飛ぶ、押すと縮む」。つまり、右へ進むほど気体、上へ進むほど液体や固体が有利になる。

模式的な状態図

固体
液体
気体

線の上では2つの状態が共存する

境界線何と何の境界か覚え方
融解曲線固体 ↔ 液体「融解」＝固体が溶けて液体になる
蒸気圧曲線液体 ↔ 気体液体から蒸気になる境界
昇華圧曲線固体 ↔ 気体液体を通らず固体から気体へ
線の上は「ちょうど変化中」と考える。例えば蒸気圧曲線上では液体と気体が共存し、三重点では固体・液体・気体の3つが共存する。
臨界点：蒸気圧曲線の終点。臨界点より高温・高圧側では、液体と気体をはっきり区別できない超臨界流体になる。

水と二酸化炭素は「1気圧の横線」で見る

水 H₂O

1.013×105 Pa、つまりほぼ1気圧で温度を上げると、状態図を横向きに進む。すると固体 → 液体 → 気体の順に境界線を通る。

教科書の水の状態図では、1気圧で約0℃が融点、約100℃が沸点になる。したがって「横線を引いて、どの領域を通るか」を見ればよい。

二酸化炭素 CO₂

CO₂では1気圧の横線が三重点より低圧側を通るため、液体領域に入れない。そのため、固体を温めると固体 → 気体と直接変化する。

これがドライアイスの昇華。状態図から「なぜ常圧で液体CO₂を見ないのか」まで説明できる。

問題210は「結晶を作る粒子」で分類する

問題の物質：（ア）塩化ナトリウム、（イ）銅、（ウ）二酸化ケイ素、（エ）二酸化炭素、（オ）アンモニア、（カ）塩化アンモニウム、（キ）エタノール、（ク）ヨウ素

1

まず金属単体を探す

銅 Cu は金属原子が自由電子を共有して並ぶので金属結晶。したがって（イ）は分子結晶ではない。

2

次にイオンからできた塩を探す

NaCl は Na+ と Cl−、NH₄Cl は NH₄+ と Cl− からなるのでイオン結晶。したがって（ア）（カ）は除外する。

3

巨大な共有結合ネットワークを探す

SiO₂ は独立した「SiO₂分子」が並ぶのではなく、SiとOが共有結合で網目状につながる共有結合の結晶。したがって（ウ）。

4

残りは分子結晶

CO₂、NH₃、エタノール、I₂は、それぞれ独立した分子どうしが分子間力で集まる。よって（エ）（オ）（キ）（ク）が分子結晶。

210の答え

設問答え理由
(1) 分子結晶をすべて（エ）（オ）（キ）（ク）CO₂、NH₃、エタノール、I₂はいずれも独立した分子が集まった結晶。
(2) 水素結合を形成する分子結晶を2つ（オ）（キ）NH₃は N–H、エタノールは O–H をもち、分子間で水素結合を作れる。
(3) 共有結合の結晶（ウ）SiO₂は原子が共有結合で三次元的につながった巨大構造。
ひっかけ：NH₄Clの NH₄+ 内部には共有結合があるが、結晶全体は NH₄+ と Cl− の静電気的引力でできているため、分類はイオン結晶。

10秒で分類する順番

金属単体 → 金属結晶
塩・イオン → イオン結晶
SiO₂など巨大網目 → 共有結合の結晶
それ以外の独立した分子 → 分子結晶

この順番で「除外」していくと、暗記量がかなり減る。問題210では、銅 → NaCl/NH₄Cl → SiO₂ を先に除くと、残り4つがそのまま分子結晶になる。

最後に30秒チェック

Q1. 状態図で右へ進むと何が上がる？

温度。右へ行くほど粒子の運動が激しくなり、気体側へ進みやすい。
Q2. 境界線の上では物質は1つの状態だけ？

いいえ。境界線上では2つの状態が共存する。三重点では3つが共存する。
Q3. 210で水素結合を作る分子結晶は？

（オ）アンモニア と （キ）エタノール。
Q4. NH₄Clはなぜ分子結晶ではない？

結晶を作る単位が NH₄⁺ と Cl⁻ というイオンだから。結晶全体はイオン結晶。
高校化学・状態図と結晶分類の復習用。教科書の図は「温度」「圧力」「境界線」を先に読むと判断しやすい。
